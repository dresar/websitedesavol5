Pertanyaan yang Sering Diajukan (FAQ)

Untuk menambah data penduduk baru:

  1. Buka menu Manajemen Penduduk
  2. Klik tombol Tambah Penduduk
  3. Isi form dengan data lengkap penduduk
  4. Klik Simpan untuk menyimpan data
Pastikan semua field yang wajib diisi sudah terisi dengan benar.

Untuk generate laporan keuangan:

  1. Buka menu Manajemen Laporan
  2. Klik tombol Generate Laporan
  3. Pilih jenis laporan Keuangan
  4. Tentukan periode laporan
  5. Pilih format output (PDF/Excel/Word)
  6. Klik Generate Laporan

Proses generate membutuhkan waktu 1-3 menit tergantung jumlah data.

Untuk mengubah tema aplikasi:

  1. Buka menu Pengaturan Sistem
  2. Pilih tab Tampilan
  3. Pilih tema yang diinginkan:
    • Terang: Tema dengan background putih
    • Gelap: Tema dengan background gelap
    • Otomatis: Mengikuti pengaturan sistem
  4. Klik Simpan Semua

Untuk backup data:

  1. Buka menu Pengaturan Sistem
  2. Pilih tab Backup
  3. Konfigurasi pengaturan backup:
    • Frekuensi backup (harian/mingguan/bulanan)
    • Waktu backup
    • Lokasi backup (lokal/cloud)
  4. Klik Buat Backup Sekarang untuk backup manual
Pastikan backup dilakukan secara berkala untuk menjaga keamanan data.

Untuk mengatur notifikasi:

  1. Buka menu Pengaturan Sistem
  2. Pilih tab Notifikasi
  3. Pilih jenis notifikasi yang ingin diaktifkan:
    • Notifikasi Email
    • Notifikasi Push
  4. Konfigurasi SMTP untuk email
  5. Pilih jenis notifikasi yang ingin diterima
  6. Set frekuensi notifikasi
